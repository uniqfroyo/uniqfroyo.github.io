# Image assets

Store each project's covers and content in its matching folder. Keep shared site assets and photography separate.

| Folder | Content |
| --- | --- |
| `cosmosai/` | Cosmos.AI covers and MCP, plugin, and skill screens |
| `isp/` | Interview Scheduling Portal covers and content |
| `evamobile/` | Exchange Mobile covers and content |
| `exchange-web/` | Exchange Web covers and screens |
| `business-hubs/` | Intranet Business Hubs assets |
| `adventure-playground/` | Game covers, animated previews, and world map |
| `tiktok-monetization/` | TikTok Monetization covers and content |
| `superformula/` | Superformula previews and graphics explanations |
| `photography/` | Photos used in the photography section |
| `shared/` | Shared site assets, including the favicon |

Reference these files as `/images/<folder>/<filename>` from page and component code.

- `intro/`: Intro ASCII 动效使用的花朵原色采样素材（flower.jpg）；lotusleaf.jpg 保留作备选。
