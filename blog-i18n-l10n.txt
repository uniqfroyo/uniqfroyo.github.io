The reason is structural. CJK and Latin scripts don't just look different — they run on different grid systems. A Chinese character is a fixed square unit, so the grid is block-based: it controls both line spacing and character spacing, and it aims for a strict, dense rectangle where every line starts and ends on the same vertical line. A Latin grid is baseline-based instead — words vary wildly in length, so alignment happens vertically along a baseline while the horizontal edge is left ragged on purpose. That's also why CJK text typically needs a much taller line-height (1.5–2× the font size, versus roughly 1.2× for Latin) — the visual density of each character just needs more room to breathe.
